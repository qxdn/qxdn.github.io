前言

因为看到了 ciallo.cc 的网站，看了眼源码比较简单，但是因为里面有几个 deprecated 的 html 标签，而且只有美咕噜的语音，所以我就自己写了一个，这里记录一下。

分析

简单来说 ciallo.cc 的网站实现就是简单的采用 marquee 标签来做一个滚动效果，采用 font 标签来做滚动内容。但是这两个标签在 mdn 上都是标记为 deprecated 的，虽然现在看所有浏览器都是支持，但是保不准哪天就哪个浏览器不支持了。所以采用 css 来重新实现一遍。
